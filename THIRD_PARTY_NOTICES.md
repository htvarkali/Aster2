## Website

The website layout, dither shader, 3D card model and strap are adapted from
[tejavarkali-hub/lanyardly](https://github.com/tejavarkali-hub/lanyardly), whose
README credits Tailark, React Bits and the React Three Fiber/Rapier ecosystem.
Aster-specific badge artwork, branding, blue palette and product copy are part
of the customization.
